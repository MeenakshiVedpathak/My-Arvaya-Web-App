# Arvaya Healthcare Patient Portal

A consumer-facing React healthcare project rebuilt around the supplied approved design reference.

## Modules
- Home
- Find Doctors
- Doctor Profile
- Appointment date/calendar and slot selection
- Review booking
- Confirmation
- ABHA Hub
- Health Records
- Lab Tests
- Wallet & Cashback
- Referral & Rewards

## Run
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
